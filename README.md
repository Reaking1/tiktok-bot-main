# 🖥️ TikTok Bot Main

*The desktop client for the TikTok Bot ecosystem.*

---

## 📖 Overview

TikTok Bot Main is the desktop application for the TikTok Bot ecosystem. Built with **JavaScript** and **Neutralino.js**, it provides a lightweight and responsive interface for interacting with the TikTok Bot backend.

The application communicates with the **tiktok-bot** backend, which is responsible for AI processing, voice generation, authentication, and cloud services. Together, they create a modular architecture that separates the user interface from the backend services, making the project easier to maintain and scale.

Whether running locally during development or connected to a cloud deployment, TikTok Bot Main serves as the central interface for managing and interacting with the AI-powered streamer assistant.
